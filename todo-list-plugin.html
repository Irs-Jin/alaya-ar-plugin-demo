To-Do List Plugin. On load, this plugin reads tasks directly from the AutoCount database via the ZZTGetDataTable API against the Master Data table ZZT_jm6data (seeded through Module Query on jinmenu6). Tasks are packed as JSON in ZZC_Description with the task code in ZZC_Code. Creating, editing or deleting a task only changes the local list — click the system toolbar Save (top-left, when Use System Toolbar is enabled) to persist to the database via the SIT host eval bridge (WebForm_DoCallback). After saving, a Save successful toast appears.
